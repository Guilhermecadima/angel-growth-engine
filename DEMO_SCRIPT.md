# Guião de demonstração ao Angel

## Abertura

“Fiz uma primeira versão para te mostrar duas coisas diferentes no mesmo sistema. A primeira é crescimento real: analisar conteúdo, preparar distribuição, acompanhar métricas e acelerar engagement. A segunda é um simulador técnico para vermos como funcionaria o dashboard de um sistema de processamento de views — mas sem enviar tráfego artificial para nenhuma plataforma.”

## Parte 1 — Growth Automation

1. Abrir **Growth Automation**.
2. Selecionar Instagram.
3. Tema: uma publicação real da barbearia.
4. Clicar **Gerar plano de crescimento**.
5. Mostrar score, ações 24 h, hooks, caption e métricas.

Frase:

“Esta é a parte que podemos realmente automatizar e usar no teu negócio sem depender de números falsos.”

## Parte 2 — monitorização

1. Voltar à Visão Geral.
2. Mostrar monitor YouTube/Spotify.
3. Fazer Snapshot.

Frase:

“A ideia é começares a ter histórico: publicaste, distribuíste, depois consegues ver se realmente cresceu.”

## Parte 3 — simulador

1. Abrir **Viewbot Simulator**.
2. Apontar para o aviso `SIMULADOR LOCAL`.
3. Executar 10 000 eventos em 90 min.
4. Mostrar progresso, rejeições, engagement e gráfico.

Frase:

“Isto é a demonstração técnica da arquitetura e do dashboard; não estou a dizer que estas views foram enviadas para o YouTube. Aqui os números são todos sintéticos.”

## Fecho

“O próximo passo, se gostares, é ligar as tuas contas/APIs autorizadas, guardar dados por cliente, fazer login, relatórios e automações programadas.”
